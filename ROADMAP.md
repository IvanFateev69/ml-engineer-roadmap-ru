# ROADMAP: 12 месяцев от нуля до junior ML Engineer

Один ученик, ~10 ч/неделю, 40 ч/месяц, ~480 ч/год. Python — с нуля, ML — с нуля.
Каркас — «сначала результат»: работающая модель в первом уроке → пересборка
снизу → наружу по стеку.

---

## 0. Принципы (кратко)

1. **Сначала результат.** Работающая модель в первый месяц, понимание — в
   следующие. Непонятое записывается в реестр «чёрных ящиков» с пометкой
   «раскроется в месяце N».
2. **Сначала baseline.** Ни один результат не засчитывается без сравнения с
   эвристикой или константой. Число baseline лежит в `metrics.json` и README.
3. **Предскажи, потом измерь.** Перед каждым замером — `prediction.md` с
   численным прогнозом (для новичка — диапазон), закоммиченный раньше файла
   результатов. Промах прогноза — не штраф, а запись «почему я ошибся».
4. **Сломай намеренно.** Раз в месяц: испортить компонент (перемешать метки,
   `lr=10`, убрать нормализацию, убрать маску) и письменно объяснить результат.
5. **Санитарный чек-лист** перед долгим обучением (с М2): переобучись на 32
   объектах до нуля потерь; стартовая потеря ≈ «случайное угадывание» (для
   C классов ≈ ln C); формы сверены; seed зафиксирован; один батч без NaN;
   время эпохи замерено.
6. **Журнал экспериментов** `journal.csv` (с М2): id, гипотеза, изменение,
   метрика train/val, время, вывод. Между соседними строками меняется ровно
   один параметр.
7. **Один новый инструмент качества в месяц:** uv+терминал (М1) → pytest+git
   (М2) → ruff/argparse/классы/пакет (М3) → конфиги как dataclass (М4) → mypy
   (М5) → pre-commit (М6) → logging (М7) → чекпоинты/детерминизм (М8) → GitHub
   Actions/MLflow/Docker (М9) → секреты/.env (М10) → eval-харнесс (М11) →
   мониторинг (М12).
8. **Тесты нарастающим итогом:** pytest → мутационная проверка → тесты метрик и
   поведения модели → gradient check → сверка с torch → контрактные тесты API →
   eval-наборы с хешем → тесты дрейфа и отката.
9. **Относительные ворота, а не абсолютные.** Зачёт проекта = «измерено,
   задокументировано, бьёт собственный baseline на заявленную величину».
   Абсолютные числа — целевой уровень, а не условие зачёта.
10. **Отчёт с разделом «где это врёт»** — обязательная часть каждого проекта.
11. **Готовые блоки запрещены там, где мы учимся внутренностям:** своя
    реализация сверяется с PyTorch до 1e-5.

Подробнее — [`docs/00-kak-uchitsya.md`](docs/00-kak-uchitsya.md).

## 3. Недельный ритм (8–10 ч)

| День/слот | Что делать | ~ч |
|-----------|-----------|-----|
| Сессия A | 1–2 урока месяца + код из урока | 2–3 |
| Сессия B | задания к урокам + разбор ошибок | 2–3 |
| Сессия C | проект месяца (пошагово) | 3–4 |
| Каждый день | 5–10 мин карточки (интервальное повторение) | — |

Каждый месяц состоит из 4 недель. Порядок внутри недели — из месячного модуля.
Резервные часы месяца тратьте на отставание, а не на опережение.

## 4. Что умеем к концу года (и чего нет)

### Умеем и можем доказать кодом (12 репозиториев, зелёный CI, 2–4 публичные ссылки)

- Писать поддерживаемый Python: пакеты, типы, ruff, pytest с мутационной
  проверкой, CLI, git, GitHub Actions.
- Взять сырые табличные данные, найти грязь и утечки, собрать воспроизводимый
  пайплайн с контрольной суммой, схемой и DVC.
- Довести классическую задачу от эвристики до бустинга с метрикой из цены
  ошибки, CV, порогом по деньгам, SHAP, поведенческими тестами.
- Объяснить и написать с нуля backprop, autograd, MLP, BPE, attention и
  трансформер — сверенные с PyTorch.
- Дообучить и задеплоить CNN, обучить мини-GPT дома и на T4, посчитать память
  до запуска.
- Завернуть модель в FastAPI, честно измерить p50/p95, ускорить CPU-инференс,
  вести MLflow, собрать образ в CI.
- Построить LLM-приложение со структурированным выводом, tool calling, RAG с
  измеренным recall@k, защитой от инъекций и бюджетом.
- Собрать eval-харнесс с bootstrap-интервалами, откалибровать LLM-судью,
  сравнить промпт и LoRA по качеству/латентности/стоимости.
- Поднять живой сервис с мониторингом дрейфа, алертом, откатом, пережить
  инцидент, написать постмортем и model card.

### Чего нет — говорим прямо

- **Распределённое обучение** (DDP/FSDP/ZeRO): определения и один необязательный
  запуск, ноль самостоятельной практики. Самая большая модель — десятки
  миллионов параметров.
- **GPU-программирование** (CUDA/Triton, ядра): только грамотность.
- **Промышленный стек данных** (Spark, Kafka, Airflow, dbt, feature store) и
  облака (AWS/GCP, Kubernetes, Terraform): понятия, руки не трогали.
- **SQL** — только минимум (sqlite3: SELECT/WHERE/GROUP BY/JOIN).
- **Широта ML**: нет временных рядов, рекомендательных систем, сегментации/
  детекции, RL, диффузионных моделей; unsupervised — только k-means и PCA.
- **Математика** — рабочая интуиция и NumPy, не университетский курс.
- **Командный опыт**: нет code review от людей, чужого легаси, спринтов.
- **Английский** — чтение README/документации со словарём (≈ A2 по техническим
  текстам); лекции и arXiv — нет.

**Вывод.** Требования «Python, pandas, sklearn, PyTorch, git, Docker, REST API,
метрики и валидация, базовый MLOps, LLM/RAG» закрыты с доказательствами.
Требования «опыт продакшн-нагрузки, распределённое обучение, большие данные,
1–2 года коммерческого опыта» — не закрыты. Реалистичная цель: стажировка или
junior ML/AI engineer.

## 5. Бэклог после года

Приоритет по близости к вакансиям:

1. **Данные и облако (3 мес):** Docker/Postgres/Terraform, оркестрация, dbt,
   Spark, Kafka; feature store; AWS/GCP free tier; Kubernetes (MiniKube).
2. **Системы и GPU (3 мес):** профилирование, activation checkpointing,
   Triton FlashAttention, DDP/FSDP; GPU MODE; How to Scale Your Model.
3. **Широта ML:** временные ряды, рекомендательные системы, сегментация/
   детекция, Kaggle-соревнования как тренажёр скорости.
4. **Post-training:** SFT/GRPO, DPO, RLHF на уровне идеи; данные для дообучения.
5. **Инференс глубже:** vLLM/PagedAttention, спекулятивное декодирование,
   continuous batching.
6. **Ответственный AI:** fairmlbook.org, NIST AI RMF / EU AI Act, безопасность
   MCP-агентов.
7. **Командная работа:** контрибуция в open source, code review от людей.
8. **Английский:** регулярное чтение README → лекции с субтитрами → arXiv.
