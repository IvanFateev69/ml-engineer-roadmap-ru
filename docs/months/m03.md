## Уроки

1. **Таблица как объект.** `read_csv`, `dtypes`, `head/info`; ловушка «числа
   прочитаны как строки» («1 200,50 ₽» → `object`); мини-блок: `re.sub` как
   чистка строк (шаблон `\d`, `[ ,]`, `+`).
2. **Отбор и фильтрация:** `loc`, `iloc`, булевы маски. От вопроса на русском к
   одной строке.
3. **Группировки:** `groupby` и `agg` — средний чек по городам и город-аномалия.
4. **МАТЕМАТИКА. Среднее врёт:** медиана, квантили, стандартное отклонение.
   Σ-нотация = цикл `for`; std = √(среднего квадрата отклонений).
5. **МАТЕМАТИКА. Распределения, гистограмма, boxplot, выбросы по 1.5·IQR.**
   Когда выброс — мусор, а когда — главный клиент.
6. **Пропуски: NaN не бывает «просто так».** Удалить / заполнить / флаг «было
   пусто» и цена каждого.
7. **МАТЕМАТИКА. Корреляция Пирсона** и почему 0.9 не значит «причина».
8. **Утечка данных: 5 способов случайно показать модели ответ.** Признак из
   будущего, дубли train/test, нормализация до разбиения, id клиента, агрегат по
   всей таблице.
9. **Разбиение по времени.** `time-split`, cutoff, доказательство
   `max(train.date) < min(valid.date)`.
10. **SQL-минимум I: та же таблица в sqlite3.** Зачем SQL, если есть pandas.
    `SELECT/WHERE/ORDER BY/GROUP BY/COUNT/AVG`; `pandas.read_sql` — тот же вопрос
    двумя языками, ответы совпадают.
11. **SQL-минимум II и merge.** `JOIN` в SQL, `merge` в pandas и размножение
    строк; ловим удвоение; `safe_merge` с ассертом на число строк.
12. **Валидация данных как код:** pandera-схема и тест, который падает на новом
    кривом файле.
13. **Воспроизводимость и DVC.** `data/raw` только для чтения, `tasks.py` вместо
    Makefile (make не работает на Windows без WSL), sha256, `dvc add`. Git
    хранит записку с адресом, а не чемодан. Идемпотентность; одна ячейка про
    parquet против CSV.
14. **Классы и объекты (Мэтиз гл. 9).** `class`, `__init__`, атрибуты, методы,
    `self`, `__repr__`, `__eq__`; перегрузка оператора на примере
    `Money.__add__`. Фундамент для dataclass, minilinear (М5) и Value (М6).
15. **Пакет и CLI:** модули, `__init__.py`, импорт из своего пакета, argparse;
    отладчик VS Code — точки останова вместо десяти `print`.
16. **ruff, dataclass и что нельзя коммитить.** `@dataclass` для записи отчёта;
    персональные данные в данных и логах: что не попадает в git.

## Задания

- `clean_prices(series)` → float + число испорченных строк.
- `describe_numeric(series)` без `describe()` — сверка с эталоном 1e-9.
- `detect_outliers_iqr(series, k)` — константная серия, NaN.
- `time_split(df, date_col, cutoff)` — тест доказывает отсутствие будущего.
- `top_cities_sql(conn, n)` — SQL `GROUP BY` через sqlite3; результат совпадает
  с pandas-версией. `join_orders_customers(conn)` — `LEFT JOIN`, число строк =
  числу заказов.
- `safe_merge(left, right, on)` — падает при изменении числа строк.
- `validate_schema(df)` — pandera, ошибка указывает колонку.
- Класс `PhotoRecord` с `__init__`, `__repr__`, `__eq__`, методом
  `is_uncertain(threshold)`.
- Разбейте выданный монолит на пакет `photosort/{io,classify,report,cli}.py`.
- Мутационная проверка: 6 тестов к `clean_prices`, автотест запускает их против
  трёх сломанных реализаций и требует, чтобы каждая была поймана.

**Критерий самопроверки:** `uv run tasks.py data` воспроизводит processed, sha256
совпадает; повторный запуск не меняет файлы; pytest зелёный, покрытие модуля
очистки ≥ 80%; pandera проходит на processed и падает на `broken.csv`; SQL-запрос
даёт тот же результат, что pandas; `report.md` содержит 4 PNG; ruff зелёный;
`data/raw` отсутствует в git, `.dvc`-файлы присутствуют.

## Проект: аудит датасета — отчёт, который нельзя оспорить

Открытый табличный датасет с русским словарём колонок (≤ 200 МБ), пайплайн
`raw → interim → processed`, ≥ 5 задокументированных проблем, EDA-отчёт с 4
графиками, один SQL-ответ, схема валидации, DVC.

**Этапы:** (1) структура проекта, `data/raw` только чтение, sha256, `dvc init`;
(2) EDA: типы, пропуски, распределения, выбросы, корреляции, 4 графика;
(3) 5+ проблем с документацией, один вопрос на pandas и SQL (ответы совпадают);
(4) функции очистки + тесты + пайплайн одной командой; (5) pandera-схема, падает
на `broken.csv`; (6) time-split с тестом; (7) `report.md`: что за данные, что
нашли, что исправили, чему нельзя верить.
