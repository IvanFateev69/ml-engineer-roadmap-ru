# М4. Классическое ML: модель, которую можно объяснить и оценить в рублях

**Цель.** Пройти цепочку эвристика → логрег → бустинг, выбрать метрику из цены
ошибки, распознать переобучение по кривым, объяснить предсказание, написать
поведенческие тесты модели и вести журнал экспериментов.

**Часы:** уроки 16 / задания 8 / карточки 4 / проект 10 / резерв 2 = **40**.

**Компетенции:** A2, A10, A11, A12.

## Уроки

1. **Сначала эвристика: три `if`, которые уже приносят пользу.** Rules of ML:
   before ML. Когда ML не нужен.
2. **МАТЕМАТИКА. Вероятность за 90 минут:** событие, частота, независимость.
   Монетки и кубики в коде, закон больших чисел.
3. **МАТЕМАТИКА. Условная вероятность и Байес:** почему тест с точностью 99%
   часто ошибается. Связь с precision.
4. **МАТЕМАТИКА. Экспонента, число e и логарифм на пальцах.** Рост «в разы»
   против «на столько-то»; ln, log₂, log-шкала. Долг М2 закрыт: стартовая потеря
   для 3 классов ≈ ln 3 ≈ 1.1.
5. **МАТЕМАТИКА. Линейная регрессия как прямая через точки; MAE, RMSE, R².**
   `y = w·x + b`; «наименьшие квадраты» как картинка; sklearn `LinearRegression`
   делает `fit`; метрики руками на 10 точках; baseline «предсказываю среднее».
6. **Логистическая регрессия:** сигмоида `1/(1+e⁻ᶻ)`, смысл коэффициентов,
   почему всё ещё линейная модель; `predict_proba` руками.
7. **Метрики под задачу:** precision, recall, F1, ROC-AUC/PR и порог из цены
   ошибки в рублях. AUC 0.9 при 1% положительных; таблица «порог → прибыль»;
   logloss как «штраф за уверенную ошибку».
8. **Кросс-валидация:** почему одна разбивка врёт. k-fold, стратификация; разброс
   между фолдами как мера доверия; «0.3% при разбросе 2% — шум».
9. **Дерево решений руками и случайный лес (1.5 ч).** Impurity и лучший порог —
   только на 12 примерах на бумаге; глубина как регулятор; сотня средних деревьев
   лучше одного идеального; `feature_importances_` и её ловушки.
10. **Градиентный бустинг:** каждая следующая модель чинит ошибки предыдущей.
    LightGBM/CatBoost, три главных гиперпараметра; лимит датасета ~100 тыс. строк
    на 4 ядрах; детерминизм (`deterministic=True`, `num_threads=1`, seed).
11. **МАТЕМАТИКА. Смещение и дисперсия** на трёх кривых обучения; регуляризация
    как штраф за уверенность (интуиция). Большие коэффициенты = хрупкая модель;
    параметр C в логреге; Ridge/Lasso.
12. **sklearn Pipeline как единственная защита от утечки** — и три приёма
    признаков. `ColumnTransformer`; та же модель с утечкой даёт +7% и
    разваливается; приёмы: кодирование категорий, масштабирование, агрегаты по
    клиенту.
13. **Объяснимость:** важность признаков и SHAP на одном клиенте. Сначала
    объяснить линейную модель руками (коэффициент × признак), потом сверить с SHAP.
14. **Поведенческие тесты модели:** инвариантность, направленность, минимальная
    функциональность. Рост задолженности должен повышать риск; смена регистра
    города — нет. Мета-проверка: тесты обязаны падать на сломанной модели.
15. **Честный эксперимент:** `journal.csv`, конфиг эксперимента как dataclass
    (из М3), seed, тест открывается один раз. Подбор гиперпараметров с лимитом
    3 часа.

## Задания

- `mae`, `rmse`, `r2` без sklearn — сверка 1e-9; константный предиктор → R² = 0.
- `sigmoid`, `logloss` — устойчивость при p=0/1, сверка с sklearn.
- `precision_recall_f1` без sklearn — класс без положительных → 0.0.
- `best_threshold(y, scores, cost_fp, cost_fn)` — асимметрия 1:100.
- Собрать Pipeline с `ColumnTransformer`; автотест ломает решение, если scaler
  обучен вне пайплайна.
- 6 поведенческих тестов к выданной модели; автотест требует, чтобы ≥ 3 падали
  на сломанной.
- `diagnose(train_curve, val_curve)` → переобучение / недообучение / норма на 6
  сценариях.
- Глубже (необязательно): `gini_impurity`, `roc_auc` через ранги, `best_split`,
  своя стратифицированная k-fold.

**Критерий самопроверки:** свои метрики = sklearn (atol 1e-9); бустинг бьёт
эвристику на закрытом тесте; два прогона с seed дают побайтово одинаковый
`metrics.json`; `journal.csv` ≥ 10 строк с гипотезой/выводом, одно изменение
между соседними; запрещённые колонки из будущего отсутствуют в признаках;
≥ 3 из 6 поведенческих тестов падают на сломанной модели; `explanations/` с 3
SHAP-объяснениями; `report.md` с расчётом экономии и допущениями; ruff зелёный.

## Проект: модель оттока с ценой ошибки

Табличные данные из М3. Цепочка эвристика → логрег → бустинг, метрика из
стоимости ошибок, порог по деньгам, SHAP для 3 клиентов, поведенческие тесты,
отчёт «сколько рублей в месяц экономит модель».

**Этапы:** (1) задача и цена ошибок в README до экспериментов; (2) эвристика =
baseline; (3) логрег в Pipeline, метрики с разбросом по фолдам; (4) 3+ новых
признака, `journal.csv`; (5) бустинг, 3–4 гиперпараметра, лимит 3 ч; (6) порог по
стоимости, таблица «порог → прибыль»; (7) SHAP для 3 клиентов + ручная сверка
одного; (8) 6 поведенческих тестов; (9) закрытый тест один раз, отчёт об экономии
и раздел «почему это может не сработать в проде».
