# М5. Линейная алгебра руками: NumPy, матрицы и своя линейная регрессия

**Цель.** Понимать shape любого массива, писать векторные операции без циклов,
реализовать линейную регрессию через нормальное уравнение и через градиентный
спуск, совпав со sklearn до 1e-6, и оформить это как типизированный пакет.

**Часы:** уроки 16 / задания 9 / карточки 4 / проект 10 / резерв 1 = **40**.

**Компетенции:** A2, A3, A1.

> Порядок математики: **производная → градиент → нормальное уравнение** (не
> наоборот).

## Уроки

1. **Зачем NumPy:** цикл на миллион чисел против одной строки. Замер ускорения;
   «данные в памяти подряд»; типичные ошибки (shape mismatch, broadcasting, dtype).
2. **МАТЕМАТИКА. Вектор как список признаков; скалярное произведение = «насколько
   похожи»; расстояние = Пифагор в n измерениях.** Норма ‖·‖; евклидово расстояние
   между строками таблицы; косинусная близость клиентов — станет k-means и
   векторным поиском в М10.
3. **МАТЕМАТИКА. Матрица как таблица и как машинка, двигающая точки;** умножаем
   2×3 на 3×2 руками. Правило внутренних размерностей; транспонирование ᵀ; слой
   сети = матрица + сдвиг.
4. **Shape-мышление и broadcasting.** 90% ошибок в ML — несовпадение
   размерностей: читаем ошибку, `reshape/transpose`, shape в комментарии; `axis` —
   «ось, которая исчезает».
5. **Индексация, маски, копия против представления.**
6. **Нормализация признаков:** без неё спуск ползёт зигзагом. Параметры только с
   train — детектор утечки.
7. **МАТЕМАТИКА. Производная как скорость:** наклон касательной, численная
   производная, потом правила для `x²`, `x³`. Символы ∂ и ∇.
8. **МАТЕМАТИКА. Градиент и градиентный спуск своими руками:** 30 строк и три
   learning rate. Ползёт / сходится / взрывается; вывод градиента MSE в 6–8
   микрошагов.
9. **МАТЕМАТИКА. Нормальное уравнение (XᵀX)⁻¹Xᵀy:** откуда — градиент MSE = 0.
   Обратная матрица как «деление для матриц»; когда матрица необратима; сверка
   кодом с градиентным спуском.
10. **Функции как значения: замыкания, декораторы, генераторы.** Функция,
    возвращающая функцию; декоратор = «обёртка»; `yield` и генератор как
    «ленивый список» — для батчей.
11. **Мини-батчи:** почему не считают градиент по всем данным сразу. Полный /
    стохастический / мини-батчный, генератор батчей через `yield`.
12. **МАТЕМАТИКА. L2 и L1: Ridge и Lasso** — что добавляется в потерю и в
    градиент. Ridge сжимает, Lasso отсекает — на графике коэффициентов.
13. **МАТЕМАТИКА. PCA как проекция:** через `np.linalg.svd`, рисуем 30-мерные
    данные на плоскости. Доля объяснённой дисперсии.
14. **k-means:** кластеры по расстоянию. Алгоритм на бумаге (назначить →
    пересчитать центры), выбор k по локтю, sklearn `KMeans`; чем «без учителя»
    отличается от всего предыдущего.
15. **Типы как документация:** аннотации, mypy на новом пакете, структура `src/`,
    `pyproject`. `--strict` — «глубже», не требование.

## Задания

- `matmul(A, B)` на списках — сверка с `np.dot`, `ValueError` с формами в тексте.
- `standardize(X)` — нулевая дисперсия, возврат параметров для теста.
- `cosine_similarity(a, b)` — ортогональные, сонаправленные, нулевой вектор →
  `ValueError`.
- `linreg_normal_equation(X, y)` — сверка со sklearn atol 1e-6 на 20 датасетах.
- `gradient_descent(X, y, lr, n_steps)` — монотонное убывание при корректном lr,
  флаг `diverged` при lr=10.
- `numeric_gradient`, `gradient_check` — относительная ошибка < 1e-6.
- `batch_iterator(X, y, batch_size, shuffle, seed)` — каждая строка ровно раз за
  эпоху.
- `timed(fn)` — декоратор; `make_counter()` — замыкание.
- `pca_2d(X)` — сверка со sklearn.PCA с точностью до знака компонент.
- `kmeans_assign`, `kmeans_update` — один шаг сверяется со sklearn; пустой кластер
  не роняет функцию.
- Аннотации к 8 функциям так, чтобы mypy (`disallow_untyped_defs`) проходил.

**Критерий самопроверки:** коэффициенты обеих реализаций = sklearn (atol 1e-6);
gradient check < 1e-6; `ValueError` с фактическими формами; lr=10 → флаг
`diverged`, не NaN; модель бьёт baseline «среднее» на ≥ 20% по MAE; mypy и ruff
зелёные; `prediction.md` раньше результатов.

## Проект: minilinear — своя библиотека линейных моделей

Устанавливаемый пакет с `LinearRegression` и `Ridge` (`fit/predict/score`),
нормальное уравнение и мини-батчный градиентный спуск с ранней остановкой,
gradient check, понятные ошибки размерностей, сверка со sklearn.

**Этапы:** (1) API и README до реализации; (2) численная производная и gradient
check как модуль; (3) мини-батчный спуск с историей потерь и ранней остановкой;
(4) нормальное уравнение + сверка со спуском и sklearn; (5) L2 и стандартизация с
сохранением параметров; (6) сообщения об ошибках размерностей + тесты; (7)
baseline «среднее» и сравнение на датасете М3 по MAE/RMSE/R²; (8) mypy, ruff,
`report.md` с графиками loss и предсказание-против-факта.
