# М1. Первый результат: чужая модель уже работает на ваших фотографиях

**Цель.** Работать в терминале, запускать готовую нейросеть, писать скрипт с
переменными, циклами, функциями и файлами, читать traceback, ловить ошибки,
делать коммиты в git и жить в uv-окружении.

**Часы:** уроки 12 / задания 8 / карточки 4 / проект 12 / резерв 4 = **40**.
Учитывает установочную неделю 0 (3 ч внутри).

**Компетенции:** A1.

> Совет: если вы совсем не программировали, уроки 1–8 идут медленно — это
> нормально. Не пропускайте терминал и traceback, они окупятся сторицей.

## Уроки

1. **Терминал за один вечер.** Где я (`pwd`), что рядом (`ls`), куда перейти
   (`cd`). Создание/удаление папок, запуск программы. Git Bash на Windows.
2. **Первая программа и `uv run`.** Переменные, `print`, числа и строки,
   f-строки. Как читать ошибку: снизу вверх — тип, файл, строка.
3. **Типы и коллекции.** `int`, `float`, `str`, `bool`; списки, словари,
   циклы `for`/`while`, условия.
4. **Функции.** Аргументы, возврат, область видимости. Функция = «именованный
   кусок логики», который можно вызвать много раз.
5. **Файлы.** Чтение/запись `csv` и `json`; `with open(...)`; кодировка UTF-8.
6. **Исключения.** `try/except`, зачем ловить `FileNotFoundError`, что писать
   в лог вместо падения.
7. **Готовая нейросеть.** Запускаем предобученную ResNet-18 (torch CPU):
   картинка → класс. Три строки магии, которые делают работу — и запись
   в реестр чёрных ящиков.
8. **Скрипт фотосортировщика.** Проходим по папке, читаем изображения,
   предсказываем класс, кладём файл в подпапку, пишем `report.csv`.
9. **Git, который спасает.** `init`, `add`, `commit`, `status`, `log`.
   `.gitignore` (зачем в реестре нет `.venv` и данных).

## Задания (с самопроверкой)

- `count_by_class(labels)` — вернуть словарь «класс → число».
- `top_k(probs, k)` — индексы k наибольших вероятностей, устойчиво к `k > len`.
- `safe_open_image(path)` — при битом файле вернуть `None`, не падать.
- `write_report_csv(rows, path)` — записать строки в CSV с заголовком.
- `count_files(folder)` — сколько файлов в папке и подпапках.
- Проведите скрипт на папке из 20 изображений, где 2 файла битые. Код должен
  вернуть 0, а в отчёте «на проверку» — 2 файла.

**Критерий самопроверки:** скрипт обрабатывает 20 фото за < 60 с на CPU;
сумма файлов по подпапкам + «на проверку» = числу входных файлов (ничего не
потеряно и не задвоено); `summary.json` содержит счётчики по классам; в git
≥ 5 коммитов, `.venv` не в индексе.

## Проект: фотосортировщик

CLI-скрипт: принимает папку с фото, раскладывает их по подпапкам-классам
(ResNet-18, 1000 классов ImageNet), пишет `report.csv` (файл, предсказанный
класс, уверенность) и `summary.json` (счётчики, число «на проверку»).
Битые файлы не роняют скрипт.

**Этапы:** (1) структура папки и README; (2) чтение папки и подсчёт; (3) вызов
модели на одном фото; (4) цикл по всем файлам; (5) отчёт CSV + JSON; (6) битые
файлы; (7) коммиты и README с разделом «Ограничения».

**Отчёт обязательно содержит раздел «Где это врёт»:** например, модель уверена
в человеке, но это не человек; сортировка по 1000 классам путает похожие.
