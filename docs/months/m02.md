# М2. Своя модель и первый деплой: ссылка, которой можно поделиться

**Цель.** Собрать датасет из ~300 фото, дообучить модель в бюджете памяти,
честно доказать превосходство над baseline, написать первые тесты и выложить
демо.

**Часы:** уроки 12 / задания 8 / карточки 4 / проект 14 / резерв 2 = **40**.

**Компетенции:** A1, A3, A10, A11.

## Уроки

1. **Baseline раньше модели.** Точность правила «самый частый класс». Результат
   без baseline — не результат.
2. **Свой датасет за вечер:** 3 класса по ~100 фото, папки как метки. Как
   снимать, как называть, зачем закрытый тест, который нельзя открывать до
   финала.
3. **Train / val / test и детерминированное разбиение.** Три выборки, seed,
   проверка пересечений по sha256 содержимого файла (переименованный дубликат —
   тоже утечка).
4. **Transfer learning:** чужие веса уже знают про края и текстуры. Заморозка
   экстрактора, замена головы под свои классы, почему работает на 300 фото.
5. **Цикл обучения глазами:** epoch, batch, loss, learning rate. Читаем готовый
   цикл `for epoch → for batch → zero_grad / forward / loss / backward / step`
   построчно. Что за цифры бегут в консоли.
6. **GPU-пакет и бюджет памяти.** Отдельное окружение с CUDA-torch, проверочный
   matmul, `num_workers=0` на Windows, таблица «размер картинки × batch» от
   доступной VRAM. Никакого AMP — почему, узнаете в М8.
7. **Санитарный чек-лист перед долгим обучением.** Переобучись на 32 фото до
   нуля потерь; стартовая потеря ≈ ln C; формы; seed; один батч без NaN; время
   эпохи. Шесть проверок, экономящих часы.
8. **Аугментации:** поворот и обрезка добавляют данных бесплатно — и когда
   вредят (аугментация, ломающая метку).
9. **matplotlib за 30 минут** и шесть картинок кривых обучения: растущий разрыв
   train/val, плато, расхождение, зазубрины — и что делать в каждом случае.
   Сломайте намеренно: обучение на перемешанных метках → val на уровне случайного.
10. **Accuracy — плохая метрика:** матрица ошибок и 10 худших ошибок глазами.
11. **Первый тест и git, который показывает, что изменилось.** `assert`,
    `test_*.py`, красный → зелёный, `@pytest.mark.parametrize` (пока как
    магическая строка). `git diff`, откат файла, `.gitignore`.
12. **Gradio за 20 строк и публикация на Hugging Face Space.** Локальное демо
    (зачёт), проверка с телефона, затем Space (цель): аккаунт, токен,
    `requirements`, холодный старт.

## Задания

- `split_dataset(files, val_ratio, seed)` — воспроизводимость, доля, отсутствие
  общих файлов.
- `check_leak(train, val)` — падает с понятным сообщением при совпадении sha256;
  тест на переименованном дубликате.
- `most_frequent_baseline(y_train, y_val)` — тест на классах 90/5/5.
- `confusion_matrix(y_true, y_pred, labels)` без sklearn — сверка со sklearn на
  100 случайных наборах.
- `top_losses(losses, paths, k)` — равные потери, `k > len`.
- `sanity_overfit(model, batch, steps)` — шаблон цикла с пропусками (вставьте
  `zero_grad/backward/step`); тест: потеря на 32 объектах < 0.05 за ≤ 200 шагов;
  ловит забытый `zero_grad()`.
- Напишите 5 своих тестов к выданной `normalize_label`; автотест проверяет, что
  они падают на сломанной реализации.

**Критерий самопроверки:** пересечение train/val/test по sha256 = 0;
`metrics.json` содержит accuracy, baseline_accuracy, n_test, причём
accuracy ≥ baseline + 15 п.п.; обучение на перемешанных метках даёт val ≤
случайное + 5 п.п.; `journal.csv` ≥ 5 строк, соседние отличаются одним
параметром; пиковая память ≤ бюджета; `prediction.md` закоммичен раньше
`metrics.json`; README содержит «Ограничения» и «Где модель ошибается».

## Проект: классификатор изображений и демо

Три класса, ~300 фото (или резервный датасет), дообученная ResNet-18/MobileNetV3,
закрытый тест, разбор ошибок, Gradio-демо; HF Space — цель, локальное демо —
зачёт.

**Этапы:** (1) датасет, разбиение, закрытие теста; (2) baseline и `prediction.md`
(коммит до обучения); (3) санитарный чек-лист, запись в `journal.csv`;
(4) обучение в бюджете, кривые, чекпоинт; (5) серия из 5 экспериментов по одному
изменению (аугментации, lr, эпохи, размер картинки, заморозка); (6) матрица
ошибок, 10 худших ошибок, исправление разметки, переобучение; (7) закрытый тест —
один раз; (8) Gradio локально, Space по возможности; (9) README с «где врёт».

## Риски

- **OOM и зависание GPU** — таблица batch от доступной VRAM и «охраняемый
  ритуал» (сохранить работу, закрыть браузер, запускать из скрипта).
- **Сборка torch под старые карты** — проверочный скрипт до обучения.
- **Цикл обучения через месяц после первой переменной** — только по шаблону.
- **Слишком лёгкий датасет** — нужен один заведомо трудный класс.
- **Регистрация на HF недоступна** — локальное демо даёт зачёт.
