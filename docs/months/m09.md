# М9. Инференс и первый настоящий сервис: FastAPI, MLflow, CI/CD

**Цель.** Завернуть модель М2 в HTTP-сервис, честно измерить p50/p95/p99 и
пропускную способность, ускорить CPU-инференс без потери качества, вести
эксперименты в MLflow с реестром, настроить CI/CD с образом Docker и добавить
фичу в чужой код.

**Часы:** уроки 13 / задания 9 / карточки 4 / проект 12 / резерв 2 = **40**.

**Компетенции:** A7, A8, A1, A11.

> Гейт Docker — необязательный: образ можно собирать только в CI.

## Уроки

1. **Модель — не продукт:** чек-лист из 8 пунктов. Интерфейс, надёжность,
   скорость, стоимость, наблюдаемость, версия, откат, документация.
2. **FastAPI за один урок:** `/predict`, `/health`, pydantic-схемы, 200/422/500.
   Схема как контракт; `@app.get` — декоратор из М5.
3. **Конкурентность за один урок:** потоки, GIL, asyncio, таймауты. Поток против
   процесса; `threading.Lock` и очередь; таймаут как обязательный параметр.
4. **Латентность честно:** p50/p95/p99 против среднего, разогрев, холодный старт.
5. **Батчинг:** 8 запросов дешевле, чем 8 раз по одному. Коллектор по размеру и
   таймауту; компромисс латентность/пропускная способность.
6. **Где уходит время:** профилирование запроса по этапам (предобработка, прогон,
   постобработка, сериализация).
7. **ONNX и квантизация int8 на CPU:** что теряем, что выигрываем. Единственный
   локальный путь ускорения; KV-кэш для генерации как понятие — замер.
8. **MLflow и реестр моделей:** что логировать обязательно. Параметры, метрики,
   артефакты, версия данных (DVC-хеш) и коммит; стадии; перенос `journal.csv`.
9. **Docker без магии:** слои, `.dockerignore`, образ на 6 ГБ — это баг.
   Многоступенчатая сборка, CPU-torch.
10. **GitHub Actions:** линт, типы, тесты, смоук-обучение, сборка образа. Красный
    крестик на своём коммите; что не влезает в бесплатные минуты.
11. **Логи, которые помогают:** structlog, `request_id`, что нельзя логировать.
12. **Нагрузочный тест:** график rps против p95 и точка насыщения. 3 прогона,
    медиана, фиксация фоновой нагрузки.
13. **Стоимость в рублях:** цена тысячи запросов на своём железе и в облаке.
    Электричество, амортизация, тарифы; prediction на эффект оптимизаций.

## Задания

- `percentile(latencies, q)` без numpy — сверка, выборка из одного элемента.
- `fetch_all_with_timeout(urls, timeout)` — `ThreadPoolExecutor`, один «зависший»
  URL не блокирует остальные; результат в исходном порядке.
- `BatchCollector(max_size, max_wait_ms)` — очередь + поток; тесты через подмену
  времени.
- `validate_request(payload)` — 6 кривых запросов → 422.
- `measure_throughput(fn, n, concurrency)` — rps и p95 на функции с фиксированной
  задержкой.
- Тест качества после квантизации: падение ≤ 1 п.п.
- `healthcheck()`/`/model-info` — версия модели, хеш весов, хеш данных, git-коммит;
  хеш меняется при подмене файла.
- `redact_log(record)` — утечка пользовательского контента ищется регуляркой.
- **Фича в чужом коде:** добавьте эндпоинт `/batch-predict` и лимит размера тела,
  не сломав существующие тесты.

**Критерий самопроверки:** httpx-контракты (200 по схеме, 422 на невалидном,
битое изображение → 422, не 500); CI зелёный, образ собран в CI, размер ≤ 1.5 ГБ;
контейнер отвечает на `/health` < 10 с; ускорение p95 ≥ 2× при падении качества
≤ 1 п.п. (зачёт — ≥ 1.3× с таблицей); в MLflow ≥ 5 прогонов с параметрами,
метриками, DVC-хешем и коммитом, ровно одна production-модель; `/model-info` —
три непустых поля; логи без пользовательского контента; 3 прогона нагрузки с
медианой; `prediction.md` раньше `bench_after.json`; 4 ранних репозитория имеют
README по шаблону и зелёный CI.

## Проект: сервис инференса с трекингом и CI/CD

FastAPI с валидацией, `/health` и `/model-info`, structlog, батчинг; бенчмарк
до/после (ONNX + int8 на CPU); MLflow с ≥ 5 прогонами и одной production-моделью;
GitHub Actions: ruff, mypy, pytest, смоук-обучение, сборка образа ≤ 1.5 ГБ;
нагрузочная кривая; стоимость 1000 запросов. Плюс ретрофит репозиториев М1–М4.

**Этапы:** (1) API + контрактные тесты; (2) `bench_before.json`; (3) prediction по
оптимизации; (4) батчинг; (5) ONNX + int8, замер; (6) MLflow + реестр +
`/model-info`; (7) `bench_after.json`, график rps/p95; (8) Dockerfile + CI; (9)
`report.md` со стоимостью; (10) ретрофит ранних репозиториев.
