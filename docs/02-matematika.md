# Математика: что, когда и ровно перед чем

Правило: формула появляется в том месяце, где без неё не решается задача,
вводится на числах текущего проекта и немедленно проверяется кодом (численная
производная против аналитической, своя метрика против sklearn). Уровень —
интуиция + счёт на пальцах + код, без доказательств.

Стартовая точка — 7 классов: нет логарифмов, корней, Σ-нотации, векторов.
Каждый символ вводится в месяц первого появления и получает карточку.

---

## Словарь символов

| Символ | Читается | Смысл | Появляется |
|--------|----------|-------|------------|
| Σ | сигма | «сложить всё по списку» (цикл `for`) | М3 |
| √ | корень | обратная к квадрату операция | М3 |
| ≈ | примерно равно | | М4 |
| e | число Эйлера | база, при которой скорость роста = значению | М4 |
| ln, log | логарифм | «сколько раз умножить» — обратная к степени | М4 |
| ∂, ∇ | частная производная, градиент | наклон по одному направлению / вектор всех наклонов | М5 |
| ‖·‖ | норма | длина вектора | М5 |
| ᵀ | транспонирование | переворот матрицы | М5 |
| ⁻¹ | обратная матрица | «деление для матриц» | М5 |
| argmax | аргмакс | «то значение аргумента, где максимум» | М5–М6 |
| ∝ | пропорционально | | М7 |

## Карта «тема → месяц → перед чем»

| Тема | Месяц | Ровно перед чем |
|------|-------|-----------------|
| Квадратный корень, Σ-нотация, описательная статистика: среднее/медиана/квантили/std, распределения, выбросы, корреляция | М3 | чтением собственного датасета |
| Вероятность, условная вероятность, Байес | М4 | логистической регрессией и precision/recall |
| Экспонента, число e, логарифм (на пальцах) | М4 | сигмоидой, logloss, «стартовая потеря ≈ ln C» |
| Линейная регрессия как прямая; MAE, RMSE, R² | М4 | логистической регрессией и minilinear |
| Bias–variance, регуляризация как штраф (интуиция) | М4 | подбором гиперпараметров |
| Векторы, скалярное произведение, норма и расстояние, матрицы, умножение, shape, broadcasting | М5 | своей линейной регрессией и k-means |
| Производная как скорость, градиент, градиентный спуск, вывод градиента MSE → нормальное уравнение | М5 | обучением minilinear |
| L1/L2: Ridge и Lasso — что добавляется в потерю и градиент | М5 | Ridge в minilinear |
| PCA как проекция (через SVD); k-means как кластеры по расстоянию | М5 | визуализацией многомерных данных |
| Цепное правило, частные производные, вычислительный граф | М6 | реализацией `backward()` |
| Правило цепочки для вероятностей, правдоподобие, энтропия, кросс-энтропия, perplexity | М7 | языковой моделью |
| Формула внимания, √d, число параметров и памяти модели | М8 | своим трансформером |
| Перцентили, латентность/пропускная способность | М9 | бенчмарком сервиса |
| Статистика вывода: стандартная ошибка, bootstrap, доверительный интервал, p-value, множественные сравнения, размер выборки | М11 | сравнением подходов и A/B |
| PSI и сравнение распределений | М12 | мониторингом дрейфа |

## Как учить формулы (метод)

1. **На числах вашего проекта.** Не на абстрактных x и y, а на колонке вашего
   датасета или на ваших токенах.
2. **Кодом.** Сразу пишете функцию и сверяете с библиотекой:
   ```python
   assert abs(my_metric(y, p) - sklearn_metric(y, p)) < 1e-9
   ```
3. **Разложением на шаги.** Любую формулу можно расписать как несколько
   присваиваний. Если не получается — тема не понята.
4. **Карточкой.** Формулировка «что означает Σ в формуле среднего и как это
   записать циклом?» — это L1-вопрос; «почему при большом learning rate ошибка
   растёт?» — уже L2–L3.

## Что НЕ нужно на этом этапе

- Доказательства и выводы «для общего развития».
- Университетский анализ, теория меры, свойства ММП-оценок.
- Ручное дифференцирование сложных выражений (кроме MSE и цепного правила —
  они нужны для М5–М6).

Математика здесь — инструмент, а не самоцель.
